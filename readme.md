## 重构想

> 我听说过这样一个作品。
>
> 它的作者，即是一位独立的制作人，也是一位神级的作曲家。
> 它的主角——两位学生，性格一动一静。
>
> ta们在课堂之外，展开活动——
>
> 寂静神秘的*开端*、超现实科幻的*梦境*、怀旧而并不漫长的*旅程*、宇宙般庄严宏伟的*氛围*……
>
> 由此共同跨越 *梦* 与 *现实* 的境界。
>
> ……
>
> 而我们都知道，这个作品的名字。
> 那便是——

**[ZUN的音乐CD系列](https://thwiki.cc/%E5%AE%98%E6%96%B9%E9%9F%B3%E4%B9%90CD#ZUN%E7%9A%84%E9%9F%B3%E4%B9%90CD) / [deltarune](deltarune.com).**

这便是重构想的源头了。


## 何为重构想-为何重构想

我们总是能找到各种各样的名词来阐释“改编”。有人喜欢称之为 *二次创作*，也有的喜欢叫它 *同人作品*；有人会把它捧作 饭制游戏*，还有人喜欢以 *平行宇宙* 一概而论之——侧重点，各有不同。

我却拿出了一个看上去还是蛮新的词儿。**“重构想”**。


我，对我热爱的作品，有一种肤浅的热爱。

我爱这个作品带来的某些气质和风格。虽然，它们大多数可能都是浮于表象的。

我不是游戏理论家。我无法探究到某个作品的方方面面——它的历史，现实，未来，相关联的一切事情——我并不清楚。

所以，我只能对它们有一种，肤浅的热爱。


而在这层肤浅的热爱上，我便也浅浅的意识到，*秘封俱乐部* 与 *deltarune* 的某些相通之处。

一个是我近年来最喜欢的音乐专辑系列——一个是某种意义上让我感到启发与共鸣的游戏作品。


这是一种共鸣。危险而又奇妙的共鸣。

我想把它们结合起来。把它们之间结合起来。把它们和 [曾经](#"DDD"是一种致敬) 的某些念想结合起来。把它们和[未来](#这个项目的趋向……)结合起来。


Reimagining —— 其意为重新想象/重构。

也许是某种意义上的幻想。

幻想一切重新开始，以一种——更熟悉又陌生——更有趣的重新演绎——或者更加把自己的某些，想投入到作品中的想法、感情、或者创造力（倘若我还有的话），把它们揉进去——的梦。


为此，我总算是下定决心，将将其[从无到有](#……以及技术栈选择)，进行构建。


至于结果如何……那便没人知道了。


###### 毕竟创作是件吃力不讨好的事情。


###### 但我总归得去做。

## "DDD"是一种致敬

###### 哇。无比正确的，显而易见的废话。

好吧，如果对我自己来说，这确实是废话。但也许真的有人不知道——deltarune 的 '精神前作'——UNDERTALE，有一个在当年还算是很有名气，名为 **[UNDERTALE DDD](https://undertale-au.fandom.com/wiki/Undertale_Distorted,_Distinctive_Destiny)** (*Undertale: Distorted Distinctive Destiny*) 的改编作品的。

那是一个动画系列，由 YouTuber Theking35 制作——一个以现在的眼光来看，有些粗糙，中规中矩的动画系列作品。

作为 undertale x touhou 的代表性作品，它一直给了我很深的印象——尽管就现在而言，也许只有印象分在整体占比中真的上了大分。

但我也确实想给这个项目起一个能让人印象深刻的名字。再加上我也是个起名废，而我印象里一直深深烙印着这个，与东方关系密切的词牌名，所以……

"DDD"是一种致敬。

致敬这个优秀的，让我印象深刻的作品；致敬那个可能远没有我印象里纯粹的，早期的创作时代。

也致敬这遥远分歧的梦。

## 这个项目的趋向……

虽然 [*“独树一帜”*](https://github.com/Bli-AIk/souprune) 之类的话已经被说烂了……

但客观（也许）的来讲。我想做的东西可能确实不是那么传统。

我最早是从动画开始做作品的，虽然没有留下什么好的作品；后来我又去写了点公式化的曲子，归根结底也就那样。

走向编程的方向后一去不复返，就迟迟难以回到最初的开始……忘记了如何踏踏实实的做作品，对一切只有朦胧的念想或渴求。

因此，我想做的东西，可能很不一样。这便是……“趋向”上的一些简单的，需要阐述的课题：

### 音乐导向

整个项目是以音乐为导向的。我将 秘封 和 dr 结合在一起的方式，便是将专辑和章节逐个映射。

而具体的演出，更多是印象为主导，而连续性相对可能会削弱——但我希望尽可能的能收得住。

### 超越视觉

deltarune 原作，某些程度上是极简主义的。至少我印象里还记得，undertale 的艺术设定集中，有“刻意营造粗糙的质感”（可能原文并非如此，我记的也不对，但——呃，那么较劲干嘛呢……）……总之，也许我可以概括为，某种简约的倾向？

但，秘封的曲目氛围，以及我个人的一些想法——让视觉上的超越，成为了某种程度上的追求。

……希望这不会太烂俗，也不会太单调。我只能尝试。毕竟我嘛，大概完全不懂美学。哈。
